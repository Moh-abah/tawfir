# 🏭 حزمة دمج مصنع «توفير» داخل tawfir-front — جاهزة بأمر واحد

> **ما هذه الحزمة؟** واجهات مصنع المنصات (الجولة 7) معدّة لتنسخ **مباشرة** داخل مشروع `tawfir-front` القائم — بدون تعديل أي ملف موجود عندك، وبدون تعارض مع أي مسار أو مخزن أو مكوّن عندك. **الكونسول معزول بالكامل** في صفحته المستقلة.

---

## ⚡ التركيب بأمر واحد (الأسرع)

1. فك ضغط هذه الحزمة في أي مكان (مثلاً سطح المكتب) — ستحصل على مجلد فيه `merge.bat` و`src` و`public`…
2. افتح CMD في مجلد الحزمة ونفّذ:

```cmd
merge.bat "E:\tawfir-full-system\tawfir-front"
```

3. بعدها:

```cmd
cd /d E:\tawfir-full-system\tawfir-front
git checkout -b factory-ui      &rem فرع أمان (مستحسن)
bun install
bun run dev
```

4. افتح:
   - **`http://localhost:3000/factory`** ← مركز المصنع (الهوية، المواقع، المناديب، التعبئة، قالب الموقع)
   - **`http://localhost:3000/console`** ← الكونسول المنفصل (معزول بالكامل)

> على لينكس/ماك: `bash merge.sh /path/to/tawfir-front`

## 🗺️ ماذا تضيف الحزمة بالضبط؟ (كلها ملفات جديدة — صفر استبدال)

| المسار بعد الدمج | ما هو | الدخول |
|---|---|---|
| `/factory` | مركز المصنع: حزمة الهوية (A) + مصنع المواقع إدارة/مالك (B) + قالب الموقع المولَّد (B′) + مناديب التاجر (D) + سكربت التعبئة وFCM (E+F) | مالك/إدارة عبر بوّابات الدخول داخل الصفحة |
| `/console` | **الكونسول المنفصل (C)** — شريط داكن خاص، تخطيط مستقل، `noindex` | `factory_admin` حصرياً |
| `src/lib/factory/` | طبقة الاتصال بالباك إند (`api.tawfir.giize.com` مدمجة — لا يحتاج أي `.env`) | — |
| `src/store/session.ts` | مخزن جلسات المصنع (مفتاح مستقل `tawfir-factory-session`) — لا يمس مخازنك | — |
| `src/components/factory/` | كل مكوّنات المصنع (11 مكوّناً) | — |
| `src/components/ui/sonner.tsx` | غلاف إشعارات sonner (حزمة `sonner` **موجودة أصلاً** في package.json عندك) | — |
| `scripts/apply-factory-manifest.mjs` | سكربت تعبئة manifest التاجر في قالب التطبيق | `node scripts/apply-factory-manifest.mjs manifest.json --root <template>` |
| `public/factory/` | نسخة السكربت قابلة للتنزيل من المتصفح | — |
| `factory-evidence/` | أدلة الاختبار الحي (manifestات + سجلات تشغيل فعلية) | — |

### ❌ ما لم تلمسه الحزمة (مضمون)
- لا يمس `src/app/(public)` ولا `(admin)` ولا `(owner)` ولا `(courier)` ولا أي ملف موجود عندك
- لا يضيف `page.tsx` على جذر `src/app` — المجموعة الجديدة `(factory)` لا تعارض مسار `/` العام
- لا يعدل `package.json` ولا `layout.tsx` الجذر ولا `globals.css` — تخطيطات المصنع تتداخل داخل التخطيط الجذر القائم عندك
- جلسات المصنع معزولة بمفتاحها — لا تختلط مع جلسات العميل/المالك/المندوب لديك

## 🔐 عزل الكونسول — كيف تحقق؟

1. **عزل بصري**: `/console` في مجموعة مسارات مستقلة `(factory-console)` بتخطيطها الخاص (شريط داكن + فوتر خاص) — لا هيدر المصنع ولا الموقع العام.
2. **عزل جلسة**: التوكن يُحفظ بمفتاح `tawfir-factory-session` المنفصل تماماً عن مخازن جلساتك.
3. **عزل توكن (من الباك إند، مثبت حياً)**: توكن الكونسول يُرفض `401` على أي مسار مالك/إدارة/عميل — والعكس صحيح.
4. **noindex**: الكونسول ممنوع الفهرسة (`robots: index:false`) — أداة داخلية.

## ✅ ملاحظات التوافق (مُتحقق منها ضد مستودع tawfir)

- نفس الأساس حرفياً: Next.js 16 App Router + React 19 + Tailwind + shadcn/ui + zustand + lucide — **نفس الإصدارات الموجودة عندك**.
- `sonner` و`next-themes` موجودان أصلاً في `package.json` عندك — لا حاجة لتثبيت أي حزمة جديدة.
- كل مكوّنات `@/components/ui/*` المستخدمة موجودة عندك (button, card, tabs, dialog, table, select, radio-group, collapsible, alert, alert-dialog, checkbox, badge, separator, input, label, textarea, tooltip) — والحزمة تضيف `sonner.tsx` الوحيد الناقص.
- خطوطك وألوان هويتك (Cairo + رموز الثيم) تُورث تلقائياً من التخطيط الجذر — المصنع سيظهر بنفس خط مشروعك.

## 🧪 تحقق سريع بعد الدمج

```cmd
cd /d E:\tawfir-full-system\tawfir-front
bun run dev
```
- `http://localhost:3000/` ← موقعك العام يعمل كما هو (لا تغيير)
- `http://localhost:3000/factory` ← مركز المصنع يعمل
- `http://localhost:3000/console` ← الكونسول المعزول يعمل

## 🚀 بعد الدمج (تشغيل ذهبي)

1. المالك يفتح `/factory` → «هويتي» → يسجل دخول المالك → يرفع الهوية حتى 100%
2. الإدارة من نفس الصفحة → «مواقع التجار» → تفعيل الموقع + فحص DNS + معاينة
3. المالك → «موقعي» يتأكد، ثم «مناديبي» ينشئ مناديبه
4. الكونسول `/console` → دخول `factory_admin` → إصدار التطبيق ببصمة فريدة → خزنة → بناء → ZIP
5. `node scripts/apply-factory-manifest.mjs manifest.json --root <template>` ثم أسرار `TAWFIR_*` في CI → AAB/APK

## 🌐 النشر لاحقاً (اختياري)

- إن أردت دومين مستقل للكونسول (مثل `console.tawfir.giize.com`): وجّه السب دومين لنفس التطبيق — العزل قائم بالتصميم (انظر `دليل_النشر_والدمج_واجهة.md` المرفق).
