## 2) قائمة اختبار الجهاز (فور بناء APK/IPA — علّم أمام كل بند)

### أندرويد (APK/AAB)
- [ ] تثبيت → إقلاع → شاشة إقلاع الهوية ثم الرئيسية داخل التطبيق (بلا شريط عنوان).
- [ ] عميل سعودي: طلب → «ادفع الآن إلكترونيًا» → شاشة الدفع: **زر Apple Pay غير ظاهر** (صحيح على أندرويد).
- [ ] بطاقة ناجحة `4201320111111010` (مدى) داخل النموذج → تحدي 3DS إن ظهر → **يبقى داخل التطبيق** → صفحة نجاح `/payment/return` داخل التطبيق.
- [ ] بطاقة 3DS frictionless `4111114005765430` → يعود تلقائياً للنجاح.
- [ ] STC Pay: إدخال الجوال → إتمام التحقق → عودة إلى `/payment/return` داخل التطبيق.
- [ ] بطاقة مرفوضة `4201320000311101` → رسالة الفشل كما تعيدها البوابة داخل التطبيق.
- [ ] زر الرجوع الأصلي أثناء النموذج: يغلق الطبقات/يعود خطوة ولا يخرج من التطبيق.
- [ ] مشاركة رابط طلب `https://tawfir.giize.com/orders/N` من واتساب → يفتح **داخل التطبيق** (App Link موثّق — تأكد من الشريط الأخضر/الفتح المباشر).
- [ ] إشعار FCM يفتح مسار الطلب داخل التطبيق (Deep link بارد).

### آيفون (IPA)
- [ ] تثبيت → إقلاع → الرئيسية، النوتش/Safe-area سليم.
- [ ] شاشة الدفع: زر ** Pay** ظاهر (iOS + وسيلة مفعلة) → الضغط يفتح **نافذة داخل التطبيق** (شريط علوي + «تم») وليس Safari الخارجي.
- [ ] داخل النافذة: زر Apple Pay يظهر → دفع تجريبي (بيئة مويسر) → صفحة نجاح داخل النافذة → «تم» → **التطبيق يعرض «مدفوع سابقًا» فوراً** (تحديث بعد الإغلاق).
- [ ] بطاقة مدى/3DS داخل النموذج (خارج النافذة) → يبقى داخل الـWKWebView حتى النجاح.
- [ ] STC Pay كأندرويد.
- [ ] Universal Link: فتح `https://tawfir.giize.com/payment/return?order=N&id=X` من Safari → يفتح التطبيق ويُكمل التحقق داخله (يتطلب `APPLE_TEAM_ID` مضبوطاً — انظر دليل النشر §3).
- [ ] إشعارات، رجوع أصلي، داكن/فاتح كأندرويد.

### ماذا لو فشل تحدٍّ بنكي في التطبيق (خطة ب)
إن رفض بنكٌ معين التحقق داخل الـWebView (نادر): المستخدم يبقى في التطبيق ويظهر له خطأ الـACS؛ نفتح له لاحقًا (إضافة بسيطة على payment-bridge: زر «أكمل الدفع في نافذة آمنة») مسار الورقة نفسه `?sf=1` — البنية جاهزة (`openInAppBrowser` مكتوبة وموثقة في payment-bridge).

## 3) بيئة الاختبار المعلومة
- الساندبوكس يحجب `cdn.moyasar.com` (403) — لذا **إتمام دفع حقيقي من نماذج الويب/الجوال يُختبر على Vercel/جهاز** ببطاقات الساندبوكس أعلاه.
- كل بند «مُنتظر على الجهاز» أعلاه يعتمد بنية أُثبتت سليمة (بناء نظيف + عقود حية) — لا مبدع نتائج لم تُعَش.
