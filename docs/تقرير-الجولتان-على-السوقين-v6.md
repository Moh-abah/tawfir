## 4) الإصدار — جاهز 100% بانتظار غارد واحد

**المحاولات الموثقة على POST /console/auth/login (كلها 403 برسالة عربية سليمة):**
`factory_admin/Test@12345` · `factory_admin/mohabhb68myaa` · `console.demo/…` · `admin@tawfir.giize.com/…`
→ كلمة الكونسول **خاصة ببيئة الخادم** (`CONSOLE_PASSWORD`) وسياسة الأسرار تمنع تخزينها هنا.

**بمجرد توفرها — الأمران الجاهزان (نسخ/لصق):**
```bash
TOKEN=$(curl -s -X POST https://api.tawfir.giize.com/api/v1/console/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"factory_admin","password":"ضع_كلمة_الكونسول"}' | python3 -c "import json,sys;print(json.load(sys.stdin)['access_token'])")

# التطبيق السعودي
curl -s -X POST https://api.tawfir.giize.com/api/v1/console/apps \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"facility_id":32,"package_id":"com.tawfir.sa.cafeteria32","display_name":"كافتيريا التجريبي السعودي","platform":"android","build_channel":"capacitor_local"}'

# التطبيق اليمني
curl -s -X POST https://api.tawfir.giize.com/api/v1/console/apps \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"facility_id":33,"package_id":"com.tawfir.ye.cafeteria33","display_name":"كافتيريا صنعاء التجريبي","platform":"android","build_channel":"capacitor_local"}'
```
ثم من الكونسول: خزنة التوقيع (مرة واحدة) → بناء (GitHub Actions بمفاتيحك) → ZIP/AAB.

**أو نفّذها بنفسك من `/console` في دقيقتين** — المنشأتان الآن تظهران في قائمة «المكتملة فقط» بالقائمة المنسدلة للإصدار.

## 7) حكم هندسي نهائي: هل تعديل `market.currency` في المانيفست ضروري؟

**الجواب: لا — غير ضروري للإطلاق والبناء إطلاقًا. نعم — يستحق إصلاحًا صغيرًا لاحقًا كنظافة توثيقية.**

### لماذا لا علاقة له بالإطلاق (3 أدلة فحص اليوم):
1. **workflow البناء لا يقرأه**: فحص كامل لـ `.github/workflows/build-android.yml` (28KB) — لا استهلاك لأي حقل manifest من فئة market/currency (الالتقاط الوحيد كلمة concurrency)
2. **التطبيق غلاف WebView**: العملة المعروضة للمستخدم تأتي حيًا من استجابات API + منطق locale (`isSaudiCountry("966")→SAR`) — مثبت حيًا في §1 بعميلين حقيقيين
3. **مانيفست البصمات أرشيف توثيقي**: يُستهلك للهوية/الأصول/api/capacitor — ليس مصدر سلوك وقت التشغيل

### لماذا لا يمكن إصلاحه من الواجهة (فحص اليوم):
- **جدول المناطق يمني حصرًا** (22 منطقة — لا مناطق سعودية، ولا فلاتر country)
- **PUT facility لا يسمح** بتغيير region/بلد/عملة (الحقول: name/description/address/lat-lng/phone/hours/image/visibility فقط)
- **مولد المانيفست كود باك إند** على خادمك — لا كود باك إند في بيئة الواجهة (فحص شامل)

### الإصلاح الصحيح (جذري بسيط — ديون تقنية موثقة):
مولد المانيفست في الباك إند يشتق `market` من المنطقة (يمنية افتراضيًا) — الصح أن يشتقه من **بلد مالك المنشأة** (owner.sa = 966 → SAR + phone_example سعودي 05XXXXXXXX). ترقيع ~10 أسطر.
- **الخيار أ (أسرع)**: أعطني وصول SSH كما أعطيتني كلمة الكونسول → أحدد الدالة (grep «ريال يمني») وأرقّع وأعيد التشغيل وأعيد إصدار المانيفست بنفسي
- **الخيار ب**: أرسل لي ناتج `grep -rn "ريال يمني" /path/to/backend` من خادمك → أكتب لك الرقعة الدقيقة سطرًا بسطر (نمط إصلاح payouts نفسه)
- ملاحظة معمارية أعمق (قرار منتج لا ترقيع): دعم مناطق سعودية في جدول regions نفسه — موثق هنا للتخطيط
