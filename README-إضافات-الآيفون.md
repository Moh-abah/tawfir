## 🚀 أول بناء (بدون أي حساب Apple — للتحقق من سلامة كل شيء)

المستودع → **Actions → "Build iOS IPA — توفير" → Run workflow**:
- `app: customer` · `version_name: 1.2.0` · `version_code: 1`
- ✅ فعّل `allow_unsigned` هذه المرة فقط (بلا أسرار Apple بعد)

سينتج **IPA غير موقّع** خلال ~35 دقيقة = تأكيد أن كل شيء يُبنى بنجاح.
